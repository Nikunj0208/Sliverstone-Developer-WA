## 7. Interactive Floor Plan Flow (Yard ➡️ BHK ➡️ Downloadable Plan)

### A. Spring Hill Plan Options:
1. **Customer taps `[ View Plans ]`:**
   - Prompt: `Choose Square Feet for Spring Hill:`
   - Buttons: `[ 84 Sq.Yd Plots ]`, `[ 124 Sq.Yd Anchor ]`
2. **If `[ 84 Sq.Yd Plots ]` selected:**
   - Prompt: `Choose BHK Option for Spring Hill:`
   - Buttons: `[ 3 BHK ]`, `[ 4 BHK ]`, `[ 5 BHK ]`
   - **Download:** Delivers high-res architectural plan file (`Spring-Hill-84SqYd-3BHK-Plan.jpg`, `4BHK`, or `5BHK`) as a downloadable WhatsApp document.
3. **If `[ 124 Sq.Yd Anchor ]` selected:**
   - Prompt: `Choose BHK Option for Spring Hill:`
   - Buttons: `[ 4 BHK ]`
   - **Download:** Delivers high-res Anchor Plot plan (`Spring-Hill-124SqYd-Anchor-Plot-Plan.jpg`) as a downloadable WhatsApp document.

### B. Applewood Plan Options:
1. **Customer taps `[ View Plans ]`:**
   - Prompt: `Choose Square Feet for Applewood:`
   - Buttons: `[ 89 Sq.Yd Plots ]`
2. **If `[ 89 Sq.Yd Plots ]` selected:**
   - Prompt: `Choose BHK Option for Applewood:`

   - **Download:** Delivers high-res architectural plan file (`Applewood-89SqYd-3BHK-Plan.jpg`, `4BHK`, or `5BHK`) as a downloadable WhatsApp document.
